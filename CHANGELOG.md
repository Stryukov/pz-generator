# Changelog

Все заметные изменения артефактов проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Версии фиксируются тегами git. Правки вносятся в раздел [Unreleased]; при достижении вехи
он переименовывается в версию с датой, ставится тег, заводится новый [Unreleased].

## [Unreleased]
### Added
- Спецификация записки (структура, вариации, источники) — Тип А.
- JSON-шаблон сборки (флаги, дословные болванки) — Тип А.
- Мини-шаблон доп-контекста для исполнителя.
- Каркас репозитория, README, заглушки контракта и флоу.
- Контракт на результат для генерирующего агента (docs/02-contract.md).
- Флоу: зафиксирована петля повторного извлечения и статусы полей (ok/assumption/missing).
- Документ извлечения и валидации: схема манифеста, контракт агента извлечения, правила валидации (пример-месяц + итоги).

- n8n workflow (импортируемый JSON) + инструкция; контракты подгружаются из репозитория, флоу статичен.

### Changed
- Флоу переведён на локальную модель: три агента (извлечение/повтор/генерация) — узлы
  `Basic LLM Chain` + под-узел `Gemma (Ollama)` вместо HTTP-запросов к Anthropic; модель
  задаётся жёстко в узле, из `Config` убраны `model` и `anthropic_version`.
- Флоу: расчёт подаётся модели текстом через новый узел `Extract Calc Text`
  (`Extract from File`), а не PDF-документом base64 (Gemma — текстовая модель).
- Флоу: контракты грузятся четырьмя `HTTP Request`-узлами (`Fetch Extraction/Schema/Spec/
  Generation`), `Load Contracts` только склеивает строки. Причина: `helpers.httpRequest`
  внутри Code-узла виснет в task-runner n8n (таймаут задачи 60 с).
- Флоу: из `Filter Subject` убрана проверка отправителя (защита от петли не нужна в топологии
  отдельного ящика ПЗ); `Prepare Inputs` кладёт выбранный расчёт под ключ `calc`.
- Флоу: узел `Prepare Inputs` — устойчивый разбор вложений (отбор PDF-расчёта по имени файла
  вместо «первого PDF» — исключаются пени/поручение/пояснительная/реестр).
- Репозиторий: удалён дубликат воркфлоу `n8n/pz-avtomat.workflow.json` (артефакт
  переименования проекта); `examples/` вынесены в `.gitignore` (реальные клиентские файлы).
- n8n/README: для self-hosted рекомендован Gotenberg как конвертер HTML→DOCX.
- Проект переименован в pz-generator; во флоу прописан docs_base_url репозитория (ветка main).
- Именование: латинское `tip` → `type`; файл исполнителя → `executor-context.md`.
- Документы разделены по этапам пайплайна и перенумерованы (00-flow, 01-extraction-contract, 02-manifest-schema, 03-validation-rules, 04-spec, 05-generation-contract).
- Контракты извлечения и генерации приведены к строгой форме (Задача/Контекст + Формат/Обязательное/Запреты/Детализация/Готово когда).
- В правила валидации добавлен референс-код для n8n Function-node.

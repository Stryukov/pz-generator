# Доп-контекст от исполнителя — что ждём и мини-шаблон

Исполнитель прикладывает эту информацию к письму с расчётом (в теле письма или отдельным
файлом). Система берёт данные из расчёта автоматически; доп-контекст **переопределяет и
дополняет** их. Чего нет ни в расчёте, ни здесь — заменяется плейсхолдером «‹…›»,
который исполнитель дозаполнит в готовом DOCX.

## Что берётся из расчёта автоматически (заполнять не нужно)
Метод расчёта, приборы учёта, тарифы и интервалы, объёмы и суммы по месяцам, факт и
коэффициент НВЦС, факт п. 203, наличие стоков ГВС и сезонность, итоги (начислено/оплачено/остаток).

## Что ждём от исполнителя

| Поле | Обязательность | Когда нужно | Если не дать |
|---|---|---|---|
| **Исполнитель (ФИО, должность)** | обязательно | всегда | плейсхолдер «‹исполнитель›» / подпись письма |
| **НПА по нормативу** | обязательно | если расчёт по нормативу | плейсхолдер «‹укажите НПА по нормативу›» |
| **Назначение объекта(ов)** | по ситуации | если важно для записки | плейсхолдер / блок можно удалить |
| **Наименование абонента** | опц. | если в расчёте некорректно/нет | из расчёта → плейсхолдер |
| **№ и дата договора** | опц. | если в расчёте нет | из расчёта → плейсхолдер |
| **Адрес объекта(ов)** | опц. | если в расчёте нет | из расчёта → плейсхолдер |
| **Режим НВЦС** | опц. | только если НЕ упрощённый (раздел XIII) | по умолчанию упрощённый п. 123(4) |
| **Договор (файл)** | опц. | для назначения/реквизитов | — |
| **Примечания** | опц. | любые уточнения | — |

---

## МИНИ-ШАБЛОН (копировать в тело письма или приложить файлом)

```
=== ДОП-КОНТЕКСТ ДЛЯ ПОЯСНИТЕЛЬНОЙ ЗАПИСКИ ===

Исполнитель (ФИО, должность): ________________________________   [обязательно]

НПА по нормативу: ____________________________________________   [если расчёт по нормативу]

Назначение объекта(ов): ______________________________________   [или напишите: УДАЛИТЬ БЛОК]

Наименование абонента: _______________________________________   [только если в расчёте нет/ошибка]

№ и дата договора: ___________________________________________   [только если в расчёте нет]

Адрес объекта(ов): ___________________________________________   [только если в расчёте нет]

Режим НВЦС: [ ] упрощённый (по умолчанию)  [ ] раздел XIII (жилой фонд)

Примечания: __________________________________________________

=== КОНЕЦ ===
```

## Подсказки по заполнению
- Пустые поля — это нормально: система подставит данные из расчёта или плейсхолдер.
- «Назначение объекта» → «УДАЛИТЬ БЛОК», если оно не имеет значения для записки.
- «Режим НВЦС» отмечайте раздел XIII только для жилого фонда; по умолчанию — упрощённый.
- Договор можно приложить файлом — из него подтянутся назначение и реквизиты.

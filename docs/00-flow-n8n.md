# n8n-флоу

> Статус: в разработке.

Приём письма по маркеру темы -> извлечение вложений и тела -> 3-шаговая обработка ->
ответное письмо с DOCX и расчётом.

## Шаги обработки
1. **Извлечение** — агент читает расчёт -> JSON-манифест (флаги + числа).
2. **Валидация** — код сверяет арифметику манифеста с расчётом.
   - Расхождение -> обратная связь агенту извлечения -> повторное извлечение с учётом ОС.
   - Если и второй раз не сошлось -> поле помечается `assumption`, значение берётся как есть,
     генерируется комментарий исполнителю.
3. **Генерация** — агент по манифесту и контракту (`docs/05-generation-contract.md`) собирает DOCX.

## Прочее
- Защита от петли (не обрабатывать собственные ответы), дедупликация писем.
- Нет расчёта в письме -> ответ «приложите расчёт».
- Ответное письмо: DOCX-записка + исходный расчёт + список комментариев исполнителю.

> структура ПЗ `docs/04-spec-type-A.md`, контракт генерации `docs/05-generation-contract.md`.

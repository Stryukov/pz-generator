# Карта колонок — Прочие ОН (xlsx: биллинг-выгрузка и её ручная доработка)

Подключается к контракту извлечения (`01-extraction-contract.md`) по типу расчёта.
Покрывает и старую биллинг-выгрузку (`V_RP_PKV_DBT_REP_UL_NACH_PAY-N.xlsx`), и
стандартизованные образцы (`1139`, `1144`).

⚠️ **Файл почти всегда доработан руками**: сотрудник выгружает расчёт из биллинга и правит его.
Поэтому **привязка к позициям колонок запрещена** — их состав, порядок и количество плавают.
Шапка бывает на 2–3 строках с объединёнными ячейками и начинается то с 1-й строки, то со 2-й.

---

## Главное правило: колонки идут ГРУППАМИ, в манифест — итог группы

Каждая величина разложена на слагаемые, и **последняя колонка группы — итоговая**.
**В манифест всегда идёт итог группы, никогда не слагаемое.**

| Группа | Слагаемые | Итог группы → манифест |
|---|---|---|
| Объём ХВС | «по прибору учета», «по нормативу» | **«Итого ХВС»** → `V_hvs` |
| Объём стоков | «Объем стоков ХВС», «Объем стоков ГВС» | **«Итого объем стоков ХВС и ГВС»** → `V_stoki` |
| Сумма ХВС | «по прибору учета», «по нормативу» | **«Итого»** → `sum_hvs` |
| Сумма стоков | «Сумма к оплате стоки ХВС», «Сумма к оплате стоки ГВС» | **«Всего к оплате стоки ХВС и ГВС»** → `sum_stoki` |

Отдельно, вне групп: «Всего к оплате (руб. с НДС)» → `month_total`.

⚠️ **Самая частая ошибка:** взять «Сумма к оплате стоки **ГВС**» вместо «**Всего** к оплате
стоки ХВС и ГВС». Это слагаемое, а не итог. Отличать по слову **«Всего»/«Итого»** в заголовке.

**Вырожденные группы.** Если ГВС в расчёте нет (частый случай), группа стоков схлопывается:
есть только «Объем стоков ХВС» и «Итого объем стоков ХВС и ГВС» (значения равны), а сумма
стоков одна. Тогда `has_gvs=false`, `V_gvs=0`, а итогом группы считается единственная колонка.

**Игнорировать подколонку «по прибору учета» у стоков ГВС**, если она встретилась: объём стоков
практически никогда не считается по прибору, её скрывают, и в расчёт она не идёт. Брать ту
колонку стоков ГВС, которая участвует в «Итого объем стоков».

## Разобранный пример (строка апреля 2025 из расчёта 1139)

Дословный фрагмент строки — и что куда идёт. Сверяйся с ним, когда сомневаешься.

| Заголовок | Значение | → манифест |
|---|---|---|
| Объект … адрес | `г.Елизово, Ленина ул., 49б кв.пом 1: Нежилое помещение…` | `abonent.address` |
| Период задолженности | `апрель 2025` | `months[].month` = `2025-04` |
| Дата, № счет-фактуры | `ЕЗ/ОД/О/0003062 от 30.04.2025` | *не используется* |
| Тариф → ХВС | `24.74` | `tariffs[].tariff_hvs` |
| Тариф → Стоки ХВС, ГВС | `77.03` | `tariffs[].tariff_vo` |
| Объем ХВС → по прибору учета | `7` | *слагаемое* → метод `calc_method="pu"` |
| Объем ХВС → по нормативу | `0` | *слагаемое* |
| Объем ХВС → **Итого ХВС** | `7` | **`V_hvs` = 7** |
| Объем стоков ХВС | `7` | *слагаемое* |
| Объем стоков ГВС → по прибору учета | `0` | **игнорировать** |
| Объем стоков ГВС | `11.638` | `V_gvs` = 11.638 |
| **Итого объем стоков ХВС и ГВС** | `18.638` | **`V_stoki` = 18.638** |
| Сумма ХВС → по прибору учета | `207.82` | *слагаемое* |
| Сумма ХВС → по нормативу | `0` | *слагаемое* |
| Сумма ХВС → **Итого** | `207.82` | **`sum_hvs` = 207.82** |
| Сумма к оплате стоки ХВС | `647.05` | *слагаемое* |
| Сумма к оплате стоки ГВС | `1075.78` | *слагаемое* — **НЕ `sum_stoki`** |
| **Всего к оплате стоки ХВС и ГВС** | `1722.83` | **`sum_stoki` = 1722.83** |
| **Всего к оплате (руб. с НДС)** | `1930.65` | **`month_total` = 1930.65** |
| Оплачено, руб. | | оплата за месяц |
| Дата, № п/п | | *не используется* |
| Остаток задолженности, руб. | | остаток |

Контроль на этой строке: `207.82 + 1722.83 = 1930.65` ✓ — сходится с `month_total`.
Если бы вместо `sum_stoki` было взято `1075.78`, сумма дала бы `1283.60 ≠ 1930.65` — то есть
**арифметическая самопроверка ловит эту ошибку сразу** (см. §«Самопроверка» контракта).

## Реквизиты и служебные строки

**Шапка над таблицей:** название расчёта; строка «[абонент], договор № […]» → `abonent.name`,
`contract_no`; строка «за период: …». Под таблицей — блок подписи «Исполнитель:» / должность /
ФИО+телефон (правило `executor_context.ispolnitel` в §4 контракта).

**Служебные строки** «Итого за [месяц]» и «Всего: объем / оплата / долг» — в `months[]`
**не включать**. «Всего: оплата» → `totals.paid`; «Всего: долг» → `totals.balance`;
`totals.charged` = сумма `month_total` (сверить с оплатой + долгом).

## НДС
Определять по **строке нумерации колонок** (см. §2 контракта): в этом семействе формулы сумм
обычно записаны явно — `12=6*4*1,2` означает **тариф без НДС**, самопроверка `×1,2` действует.
⚠️ В строке нумерации встречаются **опечатки** (в 1144 — `14=9*5+1,2`, плюс вместо звёздочки),
поэтому она лишь подсказка: решающий признак — сходится ли `V × тариф × 1,2` с суммой.
Заголовок «руб. с НДС» относится к **сумме**, не к тарифу, и конвенцию не определяет.

## Процент канализирования
Объём стоков может быть **не равен** объёму ХВС: часть стоков не попадает в канализацию, и по
договору установлен процент канализирования.

⚠️ **База — «Объем стоков ХВС» ÷ «Итого ХВС», а НЕ «Итого объем стоков» ÷ ХВС.**
Стоки ГВС в базу **не входят**: это отдельный поток, он не «канализируется» из холодной воды.
Если взять итог стоков, отношение будет прыгать от месяца к месяцу (стоки ГВС часто постоянны,
а ХВС меняется) — и каждый месяц ошибочно окажется «отдельным вариантом расчёта».

- Считать помесячно → `months[].sewage_percent`; преобладающее значение → `flags.sewage_percent`.
- `V_hvs = 0` → процент **не вычисляется**, `sewage_percent = null`. Такой месяц отдельным
  вариантом расчёта **не считается**.
- Месяцы, где процент отличается от преобладающего, перечислить в `issues.assumption` —
  это уходит комментарием исполнителю; в текст записки расхождение не выносится.
- **Причину**, по которой стоки не равны потреблению, из расчёта взять **нельзя** — её даёт
  исполнитель в доп-контексте (`executor_context.sewage_reason`). Не выдумывать.

Примеры:
- 1144: 340,405 / 1668,652 = **20,4 %** (август), 50,7413 / 248,732 = **20,4 %** (сентябрь),
  319,564 / 319,564 = **100 %** (октябрь) → преобладающий 20,4 %, октябрь отличается.
- 1139: стоки ХВС всегда равны ХВС → **100 %** во всех месяцах, пояснение не нужно.
  (Если бы базой был итог стоков, вышло бы 266 / 411 / 213 / 333 % — пять «вариантов» на пустом
  месте.)

## Особые случаи
- **Сторно-месяц**: начисление по ПУ и равное отрицательное снятие по нормативу (итог месяца
  пуст/0) → в `months[]` все объёмы и суммы = 0, `note` = «перерасчёт/сторно — проверьте».
- **Нулевой ХВС при ненулевых стоках** — это **не** сторно: бывает, что потребление ХВС = 0,
  а стоки ГВС начисляются. Месяц извлекать как есть, `note` не ставить.
- **«Корректировка долга»** — в колонке «Оплачено» (или «Дата, № п/п») вместо суммы стоит текст
  вроде `корректировка долга`. Это переплата, перенесённая с прошлых периодов. Сумму из такой
  ячейки в `months[]` не брать; поставить `months[].has_adjustment = true`. Суть корректировки
  из расчёта не видна — её даёт исполнитель в доп-контексте (см. `docs/05`).
- **НВЦС / п.203**: колонок нет → `has_nvcs=false`, `has_p203=false`. Появляются, когда
  водоканал наш: есть колонка → флаг `true` и сумма из неё, нет → `false`, не выдумывать.

`doc_type` для манифеста: `prochie-on`.

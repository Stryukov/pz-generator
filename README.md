# pz-avtomat

Автоматическая генерация пояснительных записок к расчётам задолженности за услуги
водоснабжения и водоотведения. Пайплайн: расчёт из биллинга + доп-контекст исполнителя →
ИИ по спецификации → готовый DOCX. Оркестрация — n8n.

## Статус
В разработке. Согласована спецификация для документов **Типа А** (коммерческий абонент с
платой за негативное воздействие, НВЦС). Тип Б (формальные записки с иными НПА) — отложен.

## Что в репозитории

```
pz-avtomat/
├── README.md                              — этот файл
├── docs/
│   ├── 01-spec-type-A.md                    — структура записки: блоки, вариации, источники
│   ├── 02-contract.md                      — контракт на результат (в разработке)
│   └── 03-flow-n8n.md                      — схема n8n-флоу (в разработке)
├── templates/
│   ├── document-template-type-A.json        — JSON-шаблон сборки записки (флаги, болванки)
│   └── executor-context.md               — мини-шаблон доп-контекста для исполнителя
└── CHANGELOG.md
```

## Как связаны артефакты
- **Спецификация** (`docs/01-spec-type-A.md`) — структура записки и правила формирования
  каждого блока; человекочитаемый источник истины.
- **JSON-шаблон** (`templates/document-template-type-A.json`) — та же логика машинно: флаги,
  дословные болванки (verbatim), условия и порядок сборки блоков.
- **Контракт на результат** (`docs/02-contract.md`) — общие правила генерации, схема
  JSON-манифеста, правила валидации, ограничения. *(следующий шаг)*
- **Флоу** (`docs/03-flow-n8n.md`) — как всё собирается в n8n: приём письма, извлечение,
  валидация, генерация, ответ. *(следующий шаг)*
- **Шаблон доп-контекста** (`templates/executor-context.md`) — что заполняет исполнитель.

## Архитектура обработки (3 шага)
1. **Извлечение** — ИИ читает расчёт → структурированный JSON-манифест (флаги + числа).
2. **Валидация** — код сверяет арифметику манифеста с расчётом.
3. **Генерация** — ИИ по манифесту и спецификации собирает прозу записки (DOCX).

## Глоссарий
- **ПЗ** — пояснительная записка.
- **НВЦС** — плата за негативное воздействие на централизованную систему водоотведения
  (п. 123(4) Правил № 644).
- **п. 203** — плата за сброс загрязняющих веществ сверх нормативов (самостоятельное
  начисление, не часть НВЦС).
- **ХВС / ВО** — холодное водоснабжение / водоотведение.
- **ПУ** — прибор учёта.
- **Правила № 644** — ПП РФ от 29.07.2013 № 644.

## Конвенции
- Версионирование — через историю git; суффиксы `_v2` в именах файлов не используются.
- Плейсхолдеры в записке — единый маркер `«‹…›»` (ищется через поиск по `‹`).
- Юридические болванки вставляются **дословно**, ИИ их не переписывает.
